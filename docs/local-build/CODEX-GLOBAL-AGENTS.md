# BCD repository build instructions (global Codex scope)

For all work on `sky9662/bcd-games`, including fresh upstream or feature branches, before building an IPA or modifying CI, fetch the canonical `build/ipa-infrastructure` branch from the fork and read AGENTS.md, docs/local-build/IPA-BUILD-RUNBOOK.md, docs/local-build/CI-LESSONS.md and docs/local-build/CROSS-BRANCH-BUILDS.md at its current head. Do not assume the local branch contains the latest instructions. Use GitHub tools when local Git is unavailable. Respect verified versus pending evidence, run preflight, apply only infrastructure fixes and requested feature patches to a dedicated build branch, preserve main and PRs, record new failures/fixes in the canonical branch, and require an actual verified IPA artifact. No duplicate active builds.
